Implementation & a11y

Tailwind: extend theme with the colors above under sky/ink/tint keys; radii 12/16/20/24/28; surfaces use bg-white/[.075] border-white/10 backdrop-blur-xl (light: bg-white/70 border-slate-900/10). shadcn: Dialog + Command for search, Button (ghost, 44px icon), Toggle for star (aria-pressed), Skeleton, Card, ScrollArea (horizontal). Recharts: AreaChart + Area (gradient), dashed Line for feels-like, custom Tooltip, grid 3 horizontal lines only. Icons: weather set is duotone (1.6 stroke, 20% fill), UI uses lucide-react. Dark text contrast ≥ 7:1 (#F2F6FB on #0A101C), muted ≥ 5.5:1; light muted #475569 on white ≥ 7:1. Focus ring 2px accent, 2px offset. All icon buttons are 44×44 with aria-label. Respect prefers-reduced-motion: disable lift, star pop and skeleton pulse.
